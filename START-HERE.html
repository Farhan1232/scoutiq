ScoutIQ — Setup Guide

How to run the app and check the Football Manager 26 league parser on your own save files.

You do not need an account, a server, or an internet connection to use the parser. Save files are only ever read — never modified, renamed or moved.

1. What is in this folder

FolderWhat it is
scoutiq/The application: Rust parser, Tauri desktop shell, React interface
fm26-research/Technical notes on the save format (FINDINGS.md) and the research tool used to discover it
START-HERE.htmlThis guide

Your .fm save files are not included — they are several gigabytes. You point the app at them from your own computer.

2. Install the two prerequisites

These are one-time installations. Both are free and official.

Node.js (version 20 or newer)

Download the LTS version from nodejs.org and install it.

Rust

Go to rustup.rs and follow the one-line instruction for your system.

System build tools

  • macOS — open Terminal and run xcode-select --install
  • Windows — install “Microsoft Visual Studio C++ Build Tools” and “WebView2” (Windows 11 already has WebView2)
  • Linux — install libwebkit2gtk-4.1-dev, build-essential, libssl-dev, libayatana-appindicator3-dev, librsvg2-dev

To confirm everything is ready, open a terminal and run:

node --version
cargo --version

Both should print a version number.

3. Start the app

Open a terminal, go into the scoutiq folder, and run these two commands:

npm install
npm run tauri dev

First run takes a while — Rust compiles the parser from source, which can take 5–15 minutes. Later runs start in seconds.

The ScoutIQ window opens by itself. Use Open save file to load a .fm file. The manager, club and current league appear once the save has been read (about 1–3 seconds, depending on save size).

4. Build an installable application

To produce a normal installer you can double-click:

npm run tauri build

The finished file appears under scoutiq/src-tauri/target/release/bundle/ — a .dmg on macOS, an .msi on Windows, a .deb or .AppImage on Linux.

5. Check the parser against your saves

This runs the automated tests, including the eight saves you supplied.

Step 1. Put your .fm files together in one folder.

Step 2. From inside scoutiq/src-tauri, run the command for your system, replacing the path with your own folder:

macOS / Linux:

SCOUTIQ_TEST_SAVES=/path/to/your/saves cargo test --release --lib

Windows (PowerShell):

$env:SCOUTIQ_TEST_SAVES="C:\path\to\your\saves"
cargo test --release --lib

You should see test result: ok. 95 passed; 0 failed.

To inspect one save in detail, build the inspection tool once:

cargo build --release --features research-tools --bin fm_probe

then run it on any save:

./target/release/fm_probe --deep "/path/to/your save.fm"

Two results worth explaining in advance.

Bayer Leverkusen shows “DBL”, not “Bundesliga”. The league itself is identified correctly — it is competition 22, the German top division. Football Manager only writes a competition’s name into a save when that name differs from the installed database, and in your three German saves competition 22 carries only the short code DBL. The full word “Bundesliga” is not present anywhere in those files. If you send a name list exported from the FM26 editor, it will display “Bundesliga” with no change to the program.

MSV Duisburg comes out as 2. Bundesliga, not Bundesliga. The save you supplied stores competition 23 for that club, and the save itself names 23 “2. Bundesliga”. The parser reports what the file actually contains rather than overriding it. Please confirm whether that matches the save you intended to send.

7. About the Macclesfield promotion

The three Macclesfield saves show the promotion handled the way Football Manager itself handles it:

during the season      → EFL League One   (13)
promotion just won     → EFL League One   (13)
new season prepared    → EFL Championship (12)

The middle save still says League One because Football Manager does not move a club into its new division at the moment promotion is secured — it does so at the season rollover. The parser reports the division the save actually holds, rather than the division you would expect.

9. Optional: cloud login

The app runs fully without it. Account features stay switched off unless a .env file with Supabase keys is placed in the scoutiq folder — see .env.example for the format. No credentials are included in this package, and nothing is sent anywhere without them.

Technical detail on the discovered save-file structure is in fm26-research/FINDINGS.md. Developer-level build and validation commands are in scoutiq/README.md.
